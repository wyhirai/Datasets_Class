# Datasets's class

Projeto para organizar diferentes bancos de dados para utilizar em aula.

1. **Medicaldataset.xlsx**: banco de dados do [kaggle](https://www.kaggle.com/datasets/fatemehmohammadinia/heart-attack-dataset-tarik-a-rashid) que possui 9 variáveis com 1319 observações.

2. **prostatesurvival.xlsx**: banco de dados simulado que possui 6 variáveis com 14295 observações.

3. **unidades_ANOVA.csv**: banco de dados que possui 5 variáveis com 60 observações. 
    > Utilizado para o ensino de Análise de Variância (ANOVA)

4. **notas.csv**: banco de dados referente ao capítulo de _11. Delineamentos de Medidas Repetidas (MLG4)_ do livro de [Field, 2009](https://www.amazon.com.br/Descobrindo-Estat%C3%ADstica-Usando-SPSS-Field/dp/8536319275)
    > Utilizado para o ensino de Análise de Variância com medidas repetidas
